# 柜台折价与日结约定

值班店长在当日 19:00 核对四类烘焙品的库存。炉次按上架最早分钟与到期分钟判定可售，冲突修订停用。库存按已过账业务日和分钟截取。

## 数据

炉次按 `lot` 标识，`revision` 为单据修订号，`arrival_min` 和 `display_min` 为营业日内分钟。`shelf_minutes` 从出炉计时。促销前的 `price_cents` 与收款表均用整数分。

`kind` 允许 sale、markdown_sale、damage、donation。过账表按 `movement` 去重，冲突流水保留异常证据。炉次数量应等于销售和处置量、可售量及带符号的盘亏之和。盘亏炉次不参加模型和审批。

历史表的 `remaining` 是复核时库存，`late_sales` 是从复核到下架的真实销量，`observed_day` 是该销量实际录入日期。`censored` 标识停售、断供和更早闭店造成的右删失。回放的 `daypart` 用于一周中不同工作日形态，`rain_mm` 单位为毫米。

## 模型及复核

展示时点余货、到期剩余分钟、工作日和雨量在训练截点前拟合均值和中心方差。端点销量采用带 L2 惩罚的 Huber 线性回归，残差绝对值超过四件的梯度截断。按时间分出五天校准，取有序绝对残差的有限样本分位半径。超出历史标准化距离或验证无样本时挂起折扣审批。

折价批准数受可售件数、滞销上界、柜台同品上限及本班可使用预算共同约束。账款校核分别核对商品折价和抵扣券额度，防止同一授权被重复消费。收据复核结果保留未过账实收金额和审批原因。运行证据按源文件摘要、当班策略和收据校核结果生成指纹。

## 策略对照与交叉回放

折价页同时报告当前规则选择和按风险加权的预算组合。组合模拟按柜台、商品先构造可行前沿，再合并总预算。按统一优先值、更多覆盖件数、少花折扣与稳定炉次顺序比较。预算模拟不直接改写店长审批和现金记录。

最近六个已结束业务日沿时间轴逐日拟合和盲评，以历史中位销量为对照。另做柜台留出检查，分析调店后模型效果。现金日结按收据关联柜台分类，分出可入账、暂挂、抵扣和折价金额。联营促销额从单独的活动流水计算，缺少关联账单时整笔活动进入待查。
